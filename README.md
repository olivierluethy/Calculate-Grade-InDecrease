# Calculate-Grade-InDecrease

A tiny Python command-line script that calculates the percentage change between an
original grade and a new grade.

## Features

- Prompts for an original grade and a new grade.
- Computes the percentage increase (or decrease, shown as a negative value).
- Prints the result rounded to two decimal places.

## Tech

- Python 3 (standard library only, no dependencies).

## Usage

```bash
python main.py
```

Then enter the two grades when prompted, for example:

```
Enter the original grade: 4.0
Enter the new grade: 4.5
The grade was increased by 12.50%.
```
